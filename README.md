# BankStatement
Classifies bank transactions into categories with a fastText model trained on your own categorized history.

- `train.bat` trains the model on all categorized transactions in `all_statements.xlsx`
- `import.bat` reads all bank exports in `/input`, adds transactions that are not yet in `all_statements.xlsx`,
  classifies them (and history entries still missing a category) and writes them to `new_import.xlsx`.
  A timestamped backup of `all_statements.xlsx` is written before it is updated.
- `repair_history.py` checks `all_statements.xlsx` against the exports in `/input` and writes
  `all_statements_repaired.xlsx` with a "Repair log" sheet (added missing transactions, removed double imports,
  flagged suspicious rows). `all_statements.xlsx` itself is not modified.

Supported exports: Sparkasse (George json), DKB Girokonto (old and new csv format), DKB Kreditkarte, card complete.
Overlapping exports can be placed in `/input` together. Transactions are matched by account, date and amount,
so repeated identical transactions are kept and changed export texts do not cause duplicates.

## Demo
`demo/all_statements.xlsx` contains fully synthetic, randomized transactions (generated by `demo/make_demo.py`).
Copy it to the project root and run train.bat to try the tool without your own data.
Your own statements, input files and trained models are gitignored and stay local.
